================================================================================
1. CONFIGURATION OVERVIEW
================================================================================

Apache Roller uses multiple configuration files for different aspects of the
application. Configuration can be:

- Build-time: Maven POMs, resource filtering
- Deployment-time: External properties files
- Runtime: Database-stored properties

Configuration Hierarchy:
1. Default values (hardcoded or in bundled files)
2. External configuration file (roller-custom.properties)
3. Database stored properties (roller_properties table)
4. Environment variables (Docker, cloud deployments)

================================================================================
2. ROLLER-CUSTOM.PROPERTIES (PRIMARY CONFIGURATION)
================================================================================

File: roller-custom.properties
Location: External to WAR (various locations supported)
Format: Java properties file (key=value pairs)

Default Search Locations:
1. Path specified by -Droller.custom.config system property
2. /roller-custom.properties (filesystem root)
3. ${user.home}/roller-custom.properties
4. ${catalina.base}/roller-custom.properties (Tomcat)
5. Classpath:/roller-custom.properties

Configuration Categories:

2.1 Database Configuration

# JNDI DataSource (Recommended for Production)
database.jndi.name=java:comp/env/jdbc/rollerdb

# OR Direct JDBC Configuration (Development/Testing)
database.jdbc.driverClass=com.mysql.cj.jdbc.Driver
database.jdbc.connectionURL=jdbc:mysql://localhost:3306/roller
database.jdbc.username=rolleruser
database.jdbc.password=password

# Database Provider
database.provider=org.apache.roller.weblogger.business.jpa.JPADatabaseProvider

2.2 File Storage Configuration

# Media files directory
mediafiles.storage.dir=/var/roller/mediafiles

# Search index directory
search.index.dir=/var/roller/searchindex

# Uploaded file size limit (bytes, -1 for unlimited)
uploads.maxsize=10485760

# Allowed file extensions (comma-separated)
uploads.allowed.extensions=.gif,.jpg,.jpeg,.png,.pdf,.txt

2.3 Mail Configuration

# Mail provider
mail.configurationType=properties

# SMTP settings
mail.smtp.host=smtp.example.com
mail.smtp.port=587
mail.smtp.auth=true
mail.smtp.username=user@example.com
mail.smtp.password=mailpassword
mail.smtp.starttls.enable=true

# From address
mail.from=noreply@example.com

2.4 Site Configuration

# Site short name (appears in emails, etc.)
site.shortName=Roller

# Site name
site.name=My Roller Blog Site

# Site description
site.description=A blogging community powered by Apache Roller

# Absolute URL to site
site.absoluteurl=https://www.example.com/roller

2.5 Security Configuration

# Password encryption algorithm (SHA-512 recommended)
passwds.encryption.algorithm=SHA-512

# Enable self-registration
users.registration.enabled=true

# HTTPS required for login
securelogin.enabled=false

# Remember me cookie max age (seconds)
rememberme.maxage=1209600

2.6 Comment Configuration

# Comment spam filter (enabled/disabled)
comment.spam.filter.enabled=true

# Comment authentication required
comment.authenticator.enabled=false

# Comment notification emails
comment.notification.enabled=true

2.7 Cache Configuration

# Enable caching
cache.enabled=true

# Cache provider class
cache.provider=com.opensymphony.oscache.web.WeblogCacheAdminFilter

2.8 Planet Configuration (if using Planet feature)

# Planet aggregator enabled
planet.aggregator.enabled=false

# Planet feed fetch interval (minutes)
planet.aggregator.cache.time=180

2.9 Misc Configuration

# Locale (default language)
locale.default=en_US

# Timezone
timezone.default=America/New_York

# Enable HTTPS
server.scheme=https

# Frontend page URL (if different from absolute URL)
# frontend.url=

Example Complete Configuration File:
```properties
#==================================
# Roller Custom Configuration
#==================================

# Database JNDI
database.jndi.name=java:comp/env/jdbc/rollerdb

# File Storage

# Mail SMTP

mail.smtp.port=587
mail.smtp.auth=true
mail.smtp.username=yourapp@gmail.com
```

6. LOGGING CONFIGURATION
================================================================================

File: log4j2.xml
Location: app/src/main/resources/log4j2.xml

Structure:
```xml
<Configuration status="WARN">
    <Appenders>
        <Console name="Console" target="SYSTEM_OUT">
            <PatternLayout pattern="%d{HH:mm:ss.SSS} [%t] %-5level %logger{36} - %msg%n"/>
        </Console>
        
        <File name="File" fileName="/var/log/roller/roller.log">
            <PatternLayout pattern="%d{yyyy-MM-dd HH:mm:ss} %-5p %c{1}:%L - %m%n"/>
        </File>
    </Appenders>
    
    <Loggers>
        <Logger name="org.apache.roller" level="info"/>
        <Logger name="org.hibernate" level="warn"/>
        <Logger name="org.springframework" level="warn"/>
        
        <Root level="error">
            <AppenderRef ref="Console"/>
            <AppenderRef ref="File"/>
        </Root>
    </Loggers>
</Configuration>
```

Log Levels:
- TRACE: Very detailed debugging
- DEBUG: Debugging information
- INFO: Informational messages
- WARN: Warning messages
- ERROR: Error messages
- FATAL: Fatal errors

8. TOMCAT CONTEXT CONFIGURATION
================================================================================

File: context.xml or roller.xml
Location: Tomcat conf/Catalina/localhost/roller.xml

JNDI DataSource Configuration:
```xml
<Context>
    <Resource name="jdbc/rollerdb"
              auth="Container"
              type="javax.sql.DataSource"
              username="rolleruser"
              password="password"
              driverClassName="com.mysql.cj.jdbc.Driver"
              url="jdbc:mysql://localhost:3306/roller?useUnicode=true&amp;characterEncoding=UTF-8"
              maxTotal="50"
              maxIdle="30"
              maxWaitMillis="10000"
              removeAbandonedOnBorrow="true"
              removeAbandonedTimeout="60"
              logAbandoned="true"
              validationQuery="SELECT 1"/>
              
    <!-- Roller custom config location -->
    <Parameter name="roller.custom.config" 
               value="/etc/roller/roller-custom.properties"/>
</Context>
```

14. CONFIGURATION BEST PRACTICES
================================================================================

Security:
- Never commit passwords to version control
- Use environment variables for sensitive data
- Encrypt passwords where possible
- Restrict file permissions on config files

Environment-Specific:
- Development: Use embedded Derby, enable debug logging
- Staging: Mirror production, test configurations
- Production: External database, INFO logging, HTTPS required

Externalization:
- Keep roller-custom.properties outside WAR
- Use JNDI for database connections
- Environment variables for cloud deployments

Validation:
- Test configuration changes in non-production first
- Validate syntax before deployment
- Check logs for configuration errors

15. TROUBLESHOOTING CONFIGURATION ISSUES
================================================================================

Issue: roller-custom.properties Not Found
Solution:
- Check system property: -Droller.custom.config=/path/to/file
- Verify file exists and is readable
- Check Tomcat catalina.out for startup messages

Issue: Database Connection Failures
Solution:
- Verify JDBC URL, username, password
- Check database is running and accessible
- Test with database client tool
- Review JNDI configuration in Tomcat

Issue: Mail Not Sending
Solution:
- Verify SMTP settings
- Test SMTP connection separately
- Check firewall rules
- Review SMTP authentication settings

Issue: File Uploads Not Working
Solution:
- Check file upload size limits
- Verify mediafiles.storage.dir exists and is writable
- Check file extension restrictions
- Review disk space
