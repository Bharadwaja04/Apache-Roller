================================================================================
CONFIGURATION FILES LOCATIONS
================================================================================

Application Configuration:
- roller-custom.properties → External (configured at deployment)
  Typical locations:
  - /usr/local/roller/roller-custom.properties (Linux)
  - C:\roller\roller-custom.properties (Windows)
  - User home directory
  - Specified via system property: -Droller.custom.config=/path/to/file

Logging Configuration:
- log4j2.xml → app/src/main/resources/log4j2.xml

Database Configuration:
- persistence.xml → app/src/main/resources/META-INF/persistence.xml
- roller-custom.properties (database connection details)

Web Application:
- web.xml → app/src/main/webapp/WEB-INF/web.xml
- security.xml → WEB-INF/security.xml (Spring Security)

Struts2:
- struts.xml → app/src/main/resources/struts.xml
- struts.properties → app/src/main/resources/struts.properties

RSS/Atom:
- rome.properties → app/src/main/resources/rome.properties
- propono.properties → app/src/main/resources/propono.properties
