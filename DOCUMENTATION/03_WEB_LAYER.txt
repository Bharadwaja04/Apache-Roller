================================================================================
1. WEB LAYER OVERVIEW
================================================================================

The webUI layer provides the user interface and request handling for Apache
Roller. It uses a Model-View-Controller (MVC) architecture implemented with
Apache Struts2.

Key Technologies:
- Apache Struts 2.5.29: MVC framework
- JSP (JavaServer Pages): Dynamic page generation
- Apache Velocity: Template engine for blogs
- jQuery 3.7.1: Client-side JavaScript
- Bootstrap 3.4.1: CSS framework
- Summernote 0.8.12: WYSIWYG editor
- Struts2 Bootstrap Plugin: UI components

Web Layer Components:
1. Struts2 Actions: Handle HTTP requests
2. JSP Pages: Administrative UI
3. Velocity Templates: Blog themes
4. JavaScript/CSS: Client-side resources
5. Filters and Interceptors: Request processing

3. STRUTS2 ACTIONS
================================================================================

3.1 Action Organization

Location: app/src/main/java/org/apache/roller/weblogger/ui/struts2/

Package Structure:
- core/: Core administrative actions
- editor/: Blog editing actions
- admin/: System administration actions
- user/: User profile and settings
- common/: Shared actions and utilities

Action Naming Convention:
- *Action.java: Struts2 action classes
- Example: WeblogEntryEditAction.java

3.2 Common Action Patterns

Base Action Classes:
- UIAction: Base class for all actions
- UISecureAction: Requires authentication
- UIActionPreparable: Implements Preparable interface

Request Lifecycle:
1. Filter intercepts request
2. Action.prepare() called (if Preparable)
3. Interceptors execute (validation, authentication, etc.)
4. Action.execute() or specific method invoked
5. Result rendered (JSP, JSON, redirect, etc.)
6. Response sent to client

Action Methods:
- execute(): Default action method
- save(): Save/update operations
- delete(): Delete operations
- cancel(): Cancel and redirect

Result Types:
- success: Forward to JSP
- input: Return to form (validation errors)
- error: Error page
 - json: JSON response (AJAX)
- redirect: Client-side redirect
- redirectAction: Redirect to another action

3.3 Key Action Examples

WeblogManagement Actions:
- CreateWeblogAction: Create new blog
- WeblogConfigAction: Configure blog settings
- WeblogEntryManagement: List/manage entries

Entry Editing Actions:
- WeblogEntryEditAction: Create/edit blog posts
- WeblogEntryRemoveAction: Delete blog posts
- WeblogEntryPreviewAction: Preview before publishing

Comment Management:
- CommentManagementAction: Moderate comments
- CommentApprovalAction: Approve/spam/delete

Media Management:
- MediaFileAddAction: Upload media files
- MediaFileEditAction: Edit file metadata
- MediaFileViewAction: Browse media library

User Management:
- UserAdminAction: Manage users (admin)
- UserEditAction: Edit user profile
- RegistrationAction: New user registration

3.4 Action Annotations

Common Struts2 Annotations:
- @Action: Define action mapping
- @Result: Define result mapping
- @Namespace: Set action namespace
- @InterceptorRefs: Apply interceptors
- @Validations: Define validation rules

Example:
```java
@Action(value = "entryEdit",
        results = {
            @Result(name="success", location="EntryEdit.jsp"),
            @Result(name="input", location="EntryEdit.jsp"),
            @Result(name="error", location="error.jsp")
        })
public String execute() {
    // Action logic
    return SUCCESS;
}
```

4.1 JSP Organization

Location: app/src/main/webapp/

JSP Structure:
- index.jsp: Application landing page
- /roller-ui/: Administrative interface pages
- /roller-ui/errors/: Error pages
- /WEB-INF/jsps/: Protected JSP includes

Error Pages (/roller-ui/errors/):

- denied.jsp: Security denial
- error.jsp: General error page

4.3 JSP Tag Libraries

Standard Tag Libraries:
- JSTL Core: <c:*> - Control flow, iteration
- JSTL Formatting: <fmt:*> - I18N, formatting
- JSTL Functions: <fn:*> - String manipulation

Struts2 Tags:
File: WEB-INF/jsps/taglibs-struts2.jsp (included in all JSPs)

- <s:form>: HTML forms
- <s:textfield>: Input fields
- <s:select>: Dropdown lists
- <s:checkbox>: Checkboxes
- <s:submit>: Submit buttons
- <s:url>: URL generation
- <s:property>: Property access
- <s:iterator>: Collection iteration
- <s:if>, <s:else>: Conditional rendering

Spring Security Tags:
- <sec:authorize>: Authorization checks
- <sec:authentication>: Current user info

Custom Tags (if any):
- Roller-specific tag libraries
- Located in WEB-INF/tags/ (if present)

4.4 JSP Best Practices

Separation of Concerns:
- Business logic in Actions
- Presentation logic in JSPs
- Avoid scriptlets (<% %>)
- Use tag libraries and EL

Internationalization:
- All text via <fmt:message>
- Keys defined in ApplicationResources.properties
- Support for multiple languages

Security:
- Escape all user input: <c:out>
- CSRF tokens in forms
- Authorization checks before sensitive operations

5. VELOCITY TEMPLATES (BLOG THEMES)
================================================================================

5.1 Template System Overview

Location: app/src/main/webapp/themes/

Purpose:
- Render blog frontend (public-facing pages)
- Customizable by blog owners
- Template inheritance and includes

Template Engine: Apache Velocity 2.4.1

5.2 Standard Themes

Built-in Themes:
1. basic: Simple, clean blog theme
2. basicmobile: Mobile-optimized version
3. fauxcoly: Multi-column layout
4. frontpage: Site frontpage theme
5. gaurav: Alternative design theme

Each Theme Contains:
- weblog.vm: Main blog page
- day.vm or _day.vm: Daily entries view
- permalink.vm: Single entry permalink page
- searchresults.vm: Search results page
- entry.vm: Entry content template
- sidebar.vm: Sidebar widgets
- archives.vm: Archive listings
- tags_index.vm: Tag cloud/index
- *_css.vm or style_css.vm: CSS templates
- custom_css.vm: User custom CSS
- *_header.vm, *_footer.vm: Header/footer includes

5.3 Velocity Template Language

Velocity Syntax Elements:

Variables:
- $variableName: Output variable
- $!variableName: Silent null handling
- ${variableName}: Formal notation

Directives:
- #set($var = value): Variable assignment
- #if($condition): Conditional
- #foreach($item in $list): Iteration
- #include("file"): File inclusion
- #parse("file"): Parse Velocity file
- #macro(name): Define macro

Comments:
- ## Single line comment
- #* Multi-line comment *#

Method Calls:
- $object.method()
- $object.property

5.4 Velocity Context Objects

Available in Templates:

$model: Template model (main context object)
- $model.weblog: Current blog
- $model.entries: Blog entries list
- $model.permalink: Permalink entry
- $model.searchResults: Search results

$url: URL generation object
- $url.home: Home URL
- $url.entry($entry): Entry URL
- $url.tag($tag): Tag URL

$text: I18N text object
- $text.get("key"): Get localized text

$utils: Utility object
- $utils.formatDate($date): Format date
- $utils.escapeHTML($text): HTML escaping

$request: HTTP request object
$session: HTTP session object

5.5 Template Customization

Theme Selection:
- Admin UI: Settings → Theme
- Choose from available themes
- Preview before applying

Custom CSS:
- Edit custom_css.vm in theme
- Add blog-specific styles
- Overrides default theme CSS

Template Override:
- Copy theme template
- Modify as needed
- Save as custom theme

7.2 Message Keys

Format: 
key=value

Example:
```
weblog.title=Blog Title
entry.edit=Edit Entry
comment.moderate=Moderate Comments
```

Usage in JSP:
```jsp
<fmt:message key="weblog.title"/>
<s:text name="entry.edit"/>
```

Usage in Velocity:
```velocity
$text.get("comment.moderate")
```

7.3 Locale Selection

Automatic Detection:
- Browser Accept-Language header
- User preference (if authenticated)

Manual Selection:
- User profile settings
- URL parameter: ?locale=en_US

Fallback Chain:
1. User's selected locale
2. Browser locale
3. Default locale (English)

10. FORMS AND VALIDATION
================================================================================

10.1 Form Handling

Struts2 Forms:
```jsp
<s:form action="entryEdit" method="post">
    <s:textfield name="entry.title" label="Title"/>
    <s:textarea name="entry.text" label="Content"/>
    <s:submit value="Save"/>
</s:form>
```

CSRF Protection:
- Tokens automatically added to forms
- Validated on submission
- Prevents cross-site request forgery

10.2 Validation

Validation Types:
1. Client-side: JavaScript validation
2. Server-side: Struts2 validation framework

Validation Methods:
- XML validation: *-validation.xml files
- Annotation-based: @Validations annotations
- Programmatic: validate() method in actions

Validation Rules:
- Required fields
- String length
- Email format
- URL format
- Date format
- Numeric ranges

Error Display:
```jsp
<s:fielderror/>
<s:actionerror/>
<s:actionmessage/>
```
