DOCUMENTATION STANDARDS
================================================================================

Format: Plain text (.txt files)
Line Width: 80 characters maximum
Encoding: UTF-8
Structure: Hierarchical sections with numbered headers
Cross-References: "See also:" sections in each document

Section Numbering:
1. Main sections
1.1 Sub-sections
1.1.1 Detailed sub-sections

Code Examples:
- Enclosed in ``` markers (for readability)
- Syntax indicated (java, xml, sql, properties, etc.)
- Real examples from the codebase where possible
