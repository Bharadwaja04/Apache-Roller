1. PROJECT OVERVIEW
================================================================================

Apache Roller is an open-source, enterprise-grade blog server application built 
with Java. It provides a complete blogging platform suitable for both individual 
bloggers and large-scale blog hosting sites with multiple users and groups.

Key Features:
- Multi-user and group blog support
- Full-featured blog management system
- Template-based customization using Velocity
- RSS/Atom feed support via ROME library
- Rich text editing capabilities
- Comment management and moderation
- Category and tag organization
- Media file management
- Plugin architecture for extensibility

================================================================================
2. TECHNOLOGY STACK
================================================================================

Core Technologies:
- Java 11 (minimum required version)
- Apache Maven (build and dependency management)
- Servlet API (web application framework)

Key Frameworks and Libraries:
- Apache Struts2: MVC framework for web layer
- Apache Velocity: Template engine for dynamic content rendering
- ROME: RSS and Atom feed handling
- Google Guice: Dependency injection framework
- SLF4J 1.7.36: Logging facade
- JAXB 2.3.1: XML binding

Database Support:
- Apache Derby 10.11.1.1 (embedded database for development)
- MySQL (recommended for production)
- PostgreSQL (supported)
- Other JDBC-compliant databases

Application Servers:
- Apache Tomcat (recommended)
- Eclipse Jetty 10.0.24 (development and testing)
- Other Java EE compatible servers

3. PROJECT STRUCTURE
================================================================================

The project follows a Maven multi-module structure:

roller-project/                 # Root project (parent POM)
├── app/                       # Main web application module
├── db-utils/                  # Database utilities and migration scripts
├── it-selenium/               # Selenium-based integration tests
├── assembly-release/          # Release packaging configuration
├── docs/                      # Documentation files
├── docker/                    # Docker configuration files
├── binary-includes/           # Binary dependencies and licenses
└── testing/                   # Testing utilities and resources

================================================================================
4. MODULE DESCRIPTIONS
================================================================================

4.1 app/
   Purpose: Core web application containing all business logic, web interfaces,
            and resources
   Output: WAR (Web Application Archive) file
   Key Contents:
   - Java source code (business logic, data access, web controllers)
   - JSP pages (JavaServer Pages for UI)
   - Velocity templates (blog themes and layouts)
   - Configuration files (Spring, Hibernate, etc.)
   - Static resources (CSS, JavaScript, images)

4.2 db-utils/
   Purpose: Database schema management and migration utilities
   Contains: SQL scripts, database initialization tools

4.3 it-selenium/
   Purpose: Automated browser-based integration testing
   Technology: Selenium WebDriver
   Note: Currently commented out in parent POM

4.4 assembly-release/
   Purpose: Creates distributable packages for official releases
   Output: ZIP/TAR.GZ archives with complete installation packages

4.5 docs/
   Purpose: User and developer documentation
   Formats: ASCII Doc, ODT (OpenDocument Text)
   Includes: Installation guide, user guide, template guide

6. DEPLOYMENT OPTIONS
================================================================================

6.1 Development/Testing Deployment (Maven + Jetty):
   Requirements: Java 11+, Maven 3.x
   Steps:
   1. Clone repository
   2. Run: mvn -DskipTests=true install
   3. Run: mvn jetty:run
   4. Access: http://localhost:8080/roller
   Database: Embedded Derby (in-memory, non-persistent)

6.2 Docker Deployment:
   Requirements: Docker, Docker Compose
   Steps:
   1. Clone repository
   2. Run: docker-compose up
   3. Access: http://localhost:8080/roller
   Database: PostgreSQL (containerized)

6.3 Production Deployment:
   Requirements: Java 11+, Apache Tomcat 9+, MySQL/PostgreSQL
   Steps:
   1. Build WAR file: mvn clean install
   2. Configure database (see Installation Guide)
   3. Configure roller-custom.properties
   4. Deploy WAR to Tomcat
   5. Start Tomcat and access application

Environment-specific Configuration:
- Development: Uses embedded Derby database by default
